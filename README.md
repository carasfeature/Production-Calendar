# Car0lyke and Krispy — Production Calendar

An interactive, self-contained stream calendar. Open index.html in a browser; no installation or build needed.

## Publish on GitHub Pages

1. Create a GitHub repository (a public repository works with GitHub Free).
2. Upload index.html to the repository root.
3. In Settings → Pages, choose Deploy from a branch, select main and /(root), then Save.
4. Open the website link displayed by GitHub Pages once deployment completes.

Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Use

- Add a stream idea opens a form with title, category and description. Custom ideas save with the plan and are included in exports and share links.
- All Streams groups Just Chatting first, followed by IRL and Gaming. Each category has one consistent icon: desk setup, location pin, or controller.
- The interface uses a cool slate palette with muted violet and cyber blue accents.

- Starts empty on Monday, 12 October 2026, displaying six weeks at a time.
- Drag a tile from the right-hand shelf onto a date. Drag a scheduled tile to move it.
- Click a tile for its description, category icon and stream outline. Delete removes the idea and its scheduled entry; Undo restores them. Deletions are saved and included in exports and shared snapshots.
- On narrow screens the shelf appears above the calendar. Tap a tile, choose Add To Calendar, then click a calendar day as an alternative to dragging.
- There are no daily or weekly stream limits. Multiple stream ideas can share a day.
- Each stream can occupy one date. Scheduling it again moves it.
- Remove a scheduled stream with ×. Undo reverses the latest changes in the current session.
- Plans save in the visitor's browser. There is no shared live database or login.
- Export and Import transfer plans as JSON files.
- Share plan copies a URL containing a snapshot. Opening it loads that snapshot into the recipient's browser, replacing their locally saved plan. Subsequent edits are independent. The base site URL starts empty for a new visitor.
- Keep exported backups if clearing browser storage or changing devices.

All styles, illustrations and application code are embedded in index.html. No external assets, API keys, tracking or dependencies. The sidelined rail ideas are not included in the active library.
